# Counter App

Aplicación sencilla de contador creada con Expo, React Native y TypeScript.

## Funcionalidad

- Muestra un contador que comienza en `10`.
- Toca el botón `+1` para incrementar el contador.
- Mantén presionado el botón para reiniciarlo a `0`.

## Requisitos

- Node.js y npm.
- Expo Go para probar la app en un dispositivo móvil, o un emulador compatible.

## Instalación

Instala las dependencias del proyecto:

```bash
npm install
```

## Ejecución

Inicia el servidor de desarrollo de Expo:

```bash
npm start
```

También puedes iniciar directamente para una plataforma:

```bash
npm run android
npm run ios
npm run web
```

Para probarla en un teléfono, abre Expo Go y escanea el código QR que aparece al iniciar el servidor.
